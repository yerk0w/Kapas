# 🛒 Kapas — Аналитическая платформа для Kaspi Магазина

Профессиональный сервис для высокоскоростного мониторинга и глубокого анализа товаров на Kaspi.kz с распределенным 8-поточным парсингом, хранилищем отзывов за всё время и за месяц, защитой от бана по IP и современным интерфейсом на **React 18 + Tailwind CSS**.

---

## 💬 Новое: Полноценное хранилище отзывов (Тексты, Оценки, Плюсы и Минусы)

Теперь парсер сохраняет не только цифры, но и **полную структуру каждого отзыва**:
* **Таблица `product_reviews` в SQLite**:
  * Автор отзыва
  * Оценка (1–5 звёзд)
  * Дата отзыва
  * Полный текст комментария
  * Выделенные блоки **«Достоинства» (плюсы)** и **«Недостатки» (минусы)**
  * Флаг `is_last_month` (1 — свежий за последние 30 дней, 0 — ранее).

### 🔍 Просмотр отзывов в веб-интерфейсе:
* В таблице товаров кликните на **«Всего отзывов»** или **«Отзывы за месяц»**.
* Откроется стильное модальное окно с двумя вкладками:
  1. 📅 **«За последний месяц»** (только свежие отзывы за последние 30 дней).
  2. 📚 **«За всё время»** (вся история отзывов товара).
* Фильтр по оценкам (Все, 5★, 4★, 1-3★).
* Кнопка **«Экспорт отзывов в CSV»** для скачивания отзывов конкретного товара в Excel.

## ⚡ 8-Поточный Турбо-Сбор по категориям

Система разделяет сбор данных на **8 параллельных независимых потоков** по официальным корневым категориям Kaspi:
1. 📱 **Телефоны и гаджеты**
2. 📺 **ТВ, Аудио, Видео**
3. 🏠 **Бытовая техника**
4. 💻 **Компьютеры и софт**
5. 🚗 **Автотовары**
6. 🛋️ **Мебель**
7. 💄 **Красота и здоровье**
8. 👗 **Одежда и обувь**

### 🛡️ Антибан-защита IP (Anti-Ban Shield):
* **Распределение нагрузки**: 8 потоков опрашивают разные разделы Kaspi с независимыми сессиями.
* **Микро-джиттер (100–150 мс)**: Случайная задержка между пакетами запросов исключает машинный почерк спама.
* **Safe-Backoff**: В случае получения статуса `429` поток мягко засыпает на 15 секунд и продолжает работу без риска бана IP.
* **Параллельная SQLite WAL база**: Write-Ahead Logging для бесконфликтной одновременной записи.
